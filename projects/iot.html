Smart CO₂ sensor: indoor air quality monitoring

An IoT device that measures CO₂, temperature and humidity in a room in real time and sends a notification to your phone when it is time to open a window. Readings go to the cloud, and a dashboard charts them so you can see how the air quality changes over time.

ESP32-S3 C++ (Arduino) Sensirion SCD40 InfluxDB Cloud ntfy.sh
View on GitHub All projects

How it works

From sensor to phone notification

  • The Sensirion SCD40 sensor measures CO₂, temperature and humidity every 5 seconds.
  • The ESP32-S3 microcontroller averages the readings and sends them over WiFi to InfluxDB Cloud every 30–60 seconds.
  • An InfluxDB dashboard shows the CO₂ and temperature history.
  • When CO₂ goes above 1200 ppm, a push notification arrives on the phone via ntfy.sh. The alert has hysteresis: it only clears once CO₂ drops below 1000 ppm, so it doesn't spam you. If the air is still bad, a reminder comes every 30 minutes.
SCD40 (I2C, every 5 s) → ESP32-S3 (averaging) → WiFi / HTTPS
        → InfluxDB Cloud → dashboard
        → ntfy.sh → push notification (CO₂ > 1200 ppm)

For developers

Technical challenges

  • I2C bus diagnostics: separate tools to scan device addresses and check the SDA/SCL line levels.
  • Secure communication: TLS certificate validation instead of setInsecure(), so the API token never travels over an unverified connection.
  • Weak WiFi signal: the device reconnects to the network on its own.
  • Alerting in firmware, not in the cloud: it doesn't depend on paid InfluxDB features.

Stack

ESP32-S3 C++ (Arduino) I2C WiFi NTP HTTPS + TLS validation InfluxDB Cloud (line protocol) ntfy.sh
